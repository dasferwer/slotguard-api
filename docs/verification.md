# Проверки от 27 сентября 2026 года

- Ruff: правила и форматирование проверены.
- mypy: ошибок в 33 модулях исходного кода нет.
- pytest с отдельным PostgreSQL: 18 тестов прошли.
- Двенадцать одновременных запросов с одним ключом создали одну бронь,
  один сохранённый ответ и одну запись аудита.
- Конкурентные пересекающиеся брони получили один успешный ответ и конфликты `409`.
- Одновременные изменение и отмена одной версии дали `200` и `412`.
- Проверены обе формы деактивации комнаты при конкурентном создании брони.
- Сбой аудита откатил бронь и ключ повтора; повтор после сбоя прошёл.
- Конфликт переноса сохранил исходную версию и не оставил ложного события аудита.
- Тайм-аут блокировки вернул `503` с `Retry-After`; повтор после освобождения прошёл.
- Ограничение пересечений проверено прямой записью в БД в обход сервисного слоя.
- Откат и повторное применение новой миграции сохранили контрольную сумму
  пользователей, комнат, броней и аудита в тестовой БД.
- Полный Compose-стенд собран и запущен; `/health` вернул `200`, БД доступна.
  API работает под UID 10001, порт опубликован на `127.0.0.1`.

Конкурентные проверки используют несколько потоков запросов и независимые
сессии PostgreSQL. Это проверки корректности, а не нагрузочный тест.
Отказ PostgreSQL во время неопределённого результата `COMMIT`, восстановление
из резервной копии и многосерверная эксплуатация отдельно не проверялись.
Браузерная проверка Swagger UI не проводилась; HTTP-контракт проверен тестами.

[GitHub Actions](https://github.com/dasferwer/slotguard-api/actions/workflows/ci.yml)
повторяет автоматические проверки для опубликованных коммитов.
